# tramastudio

Sitio de tramastudio. Es un sitio estático: `index.html`, `assets/` (imágenes originales), `media/` (lo que se sube desde el editor), `data/works.json` (los trabajos) y `vendor/` (Preact, licencia MIT).

Para editar los trabajos, abrir el sitio con `?edit` al final de la dirección e ingresar una clave de GitHub con permiso de escritura sobre este repositorio. Cada cambio se guarda acá y se publica solo en 1 o 2 minutos.
